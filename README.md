# Controle financeiro

Aplicativo de terminal para registrar receitas e despesas e acompanhar o saldo. Os valores são guardados como centavos inteiros para evitar erros de arredondamento.

## Executar

Na pasta `dev_py`, use:

```powershell
python .\projetos\controle_financeiro\main.py
```

O programa cria `transacoes.json` quando o primeiro lançamento é feito. Esse arquivo fica no computador e está excluído do Git.
